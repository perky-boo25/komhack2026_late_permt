# OVERVIEW

awSOS is a local-based mobile application designed to enable faster information dissemination and emergency response within a specific municipality. It serves as a centralized platform for streamlined communication between residents and responders.

Residents can instantly report emergencies, while the MDRRMO (Municipal Disaster Risk Reduction and Management Office) is promptly informed and able to respond with the necessary aid.

Currently, the application is designed for online use within a specific municipality. However, with further development, it can be expanded to support offline functionality and accommodate multiple municipalities.

## Future Improvements & Challenges
The development team identified several enhancements for future implementation:
- Support for offline functionality
- Expansion to multiple municipalities
- Improved system scalability and responsiveness
- Enhanced coordination between responders
- Implementation of stronger security measures, including secure authentication and role-based access control
- Data protection and encryption to ensure the safety of user reports and sensitive information
- Validation and verification mechanisms to prevent false or malicious emergency reports
- Secure handling of location data to protect user privacy

## Notification System (Planned Feature)
The developers aim to implement dynamic elements within the responder dashboard, including:
- Real-time updates based on active alerts
- Alert indicators to notify responders of ongoing emergencies
- Automatic status updates for responders handling active alerts
- Visibility of active responders within the Teams tab 


# HIGHLIGHTS
The application includes the following key features:
- Instant emergency reporting
- Use of local language to promote inclusivity and accessibility
- Location-based reporting using OpenStreet API
- Simple and intuitive UI/UX design
- Responder account management system
- Centralized disaster reporting and response platform
- Tracking and display of past emergency records

# USAGE
The app accommodates two user groups: the residents and the responders.

## For Residents
- No account creation required (location information only)
- Dashboard displays detected location and a central emergency button
- Emergency Actions:
  - Single Tap: Report non-critical emergencies (allows user input)
  - Long Press: Report critical emergencies (with progress indicator)

## For Responders
- Account creation is required for tracking availability
- Admins manage and assign responder accounts

Responders can:
- View and track alerts
- Assign themselves to emergencies
- Monitor active alert locations 



# INSTALLATION

Simple, understandable installation instructions!

## Installation (APK)
To install and use awSOS on your Android device, follow these steps:
Prerequisites
- Android device (Android 5.0 or higher recommended)
- Internet connection (required for full functionality)

Steps
- Download the APK file
- Obtain the latest awSOS.apk from the GDrive folder linked above.
- Enable Unknown Sources
- Go to Settings > Security
- Enable “Install unknown apps” or “Allow from this source” for your browser or file manager
- Install the APK
- Locate the downloaded APK file in your device
- Tap the file and select Install
- Open the App
- Once installed, launch the awSOS application on your device.

## Notes
The application requires an internet connection for real-time reporting and responder updates.
Ensure location services are enabled for accurate emergency reporting.
Some features (e.g., responder access) require authorized accounts.
